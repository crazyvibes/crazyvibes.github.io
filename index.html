Spotshunt

Independent Product / Personal Project

Overview

Spotshunt is a location-based business discovery and growth platform I designed and built independently end-to-end, as founder and sole technical owner — native Android and iOS apps, a marketing/sponsor website, an admin dashboard, and a shared backend, all built from the ground up on a single Firebase platform.

My Role
  • Product Strategy
  • Full-Stack Architecture
  • Native Android Development
  • Native iOS Development
  • Backend & Cloud Functions
  • Admin Dashboard
Technical Challenges
01
Server-Authoritative Gamification

All XP awards, spot check-ins, and rewards are validated in Cloud Functions rather than trusted from the client, with a layered location-security check — mock-location detection, movement/speed validation, and proximity checks — on both Android and iOS before any XP is granted.

02
Real-Time Geospatial Discovery

GeoHash-indexed Firestore queries power live map-based discovery within a fixed radius across custom categories, rendered natively on Android (Maps Compose) and iOS (Apple Maps).

03
Cross-Platform Feature Parity

iOS was built from scratch to match the Android app's Clean/MVVM architecture, Firestore schema, and XP/security logic one-to-one, tracked against a formal feature-parity matrix.

04
QR Reward Redemption

An end-to-end reward pipeline — catalog, QR code generation, camera-based scanning, and server-validated redemption with expiry and audit history — shared across both mobile platforms.

05
Community Moderation

A spot-reporting and spam pipeline with configurable auto-blocking thresholds, a full audit trail, and an admin dashboard moderation queue.

06
Security Hardening

A cross-cutting security initiative — rate limiting, input validation and sanitization, and Firebase App Check — applied uniformly across the web, backend, Android, and iOS codebases.
